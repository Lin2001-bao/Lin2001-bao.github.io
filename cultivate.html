使用方法

选择当前境界与前 / 中 / 后期，填入修炼速度和已修为，点击「开始推演」，即可看到突破下一阶段、晋级下一境界分别还需多少修为、预计何时达成。

功法百分比已计入速度；玉骨 / 阴阳 / 天命 / 九转 / 关系位 / 聚灵丹 / 战意的逐项加成数值以游戏内为准，暂未自动换算，修炼速度可手动填写。结果仅供参考，请结合游戏实际机制使用。
